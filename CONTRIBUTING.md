# Руководство для участников / Contributing Guide

Мы приветствуем вклад в развитие **Unified SmartDNS + Transparent SNI Proxy Installer**.

## Требования к изменениям (Pull Requests)

1. **Проверка синтаксиса и статический анализ:** все изменения в Bash-скриптах должны проходить локальную проверку без предупреждений:

   Проверка синтаксиса:
   ```bash
   bash -n smartdns-installer-v2.10.0-stealth.sh
   ```

   Статический анализ ShellCheck:
   ```bash
   shellcheck -S warning \
     -e SC1090,SC2034,SC2154 \
     smartdns-installer-v2.10.0-stealth.sh
   ```

2. **Двуязычная локализация (`RU / EN`):** любые новые пользовательские сообщения, подсказки и заголовки должны регистрироваться одновременно в обоих словарях (`MSG_RU` и `MSG_EN`) без хардкода кириллицы в логике вывода.
3. **Транзакционность и безопасность:** изменения не должны нарушать работу механизма отката (`--rollback`), права непривилегированных пользователей (`xray`, `oxidns`, `adguardhome`, `nginx`) и изоляцию внутренних портов.
4. **Документация:** при добавлении новых флагов CLI или изменении поведения обновляйте `README.md`, `README_EN.md` и `CHANGELOG.md`.

## Порядок работы

1. Создайте форк репозитория и ответвление от ветки `main` (`git checkout -b feat/my-feature`).
2. Внесите изменения и проверьте их на тестовом сервере Debian 12/13 или Ubuntu 22.04/24.04 (`--preflight`, `--install`, `--test`).
3. Отправьте Pull Request, заполнив чек-лист в шаблоне PR.
